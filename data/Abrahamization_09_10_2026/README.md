# Information on dataset `Abrahamization_09_10_2026.xlsx`

**File name:** `Abrahamization_09_10_2026.xlsx`

**Title:** Data on Abrahamization for 920 human societies from the Ethnographic
  Atlas

**Author:** Oliver Sheehan

**Date created:** 9th October 2026

**Dimensions:** 920 rows x 2 columns

**Data dictionary:**

- `society_xd_id` - Character. Society xd_id in D-PLACE (see 
  [here](https://d-place.org/glossary#q9) for more information).
- `Abrahamization` - Numeric. An three-level ordinal variable capturing the 
  extent of Abrahamization for the society. 0 = no Abrahamization, 1 = 
  superficially Abrahamized, 2 = deeply Abrahamized.
